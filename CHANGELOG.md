# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- GitHub Actions CI/CD workflows for Node.js, Python, and Rust
- Codecov integration for coverage reporting
- `.editorconfig` for consistent coding styles across editors
- `.gitattributes` for line ending normalization
- `codecov.yml` for coverage tracking configuration
- `pyproject.toml` for Python project configuration (black, ruff)
- `pytest.ini` for Python testing configuration
- Contributing guidelines (`CONTRIBUTING.md`)
- Code of Conduct (`CODE_OF_CONDUCT.md`)
- Security policy (`SECURITY.md`)
- GitHub issue and pull request templates
- ESLint and Prettier configuration for TypeScript/JavaScript
- CODEOWNERS file for code ownership

### Changed
- Improved README with badges and quickstart guide
- Enhanced package.json with additional npm scripts

### Fixed
- Line ending issues across platforms via `.gitattributes`
- Consistent formatting with Prettier
